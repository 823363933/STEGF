# Static Grid 共享证据训练计划

## 1. 文档目的

本文档记录 STEGF 下一阶段围绕 static grid 的实验计划。后续严格按本文档逐项实施、逐项验证；前一项尚未得到明确结论时，不叠加后一项机制。

本轮研究目标不是让 static grid 严格对应物理静态物体，而是让它优先吸收稳定、重复、能够被跨视角和跨时间共同解释的外观证据，同时限制它记忆动态错位、短暂时间切片和几何补偿误差。不能形成共享解释的残差继续交给逐高斯颜色、运动和生命周期参数。

本计划不修改运动函数、不重新设计生命周期、不改变 Gaussian 初始化、不首先改变网格分辨率，也不引入动态分割、语义掩码、外部教师或额外深度先验。

## 2. 基础版本与不可变边界

所有实验以当前稳定最优模型为基础：

- 模型行为：`S2.0.4-couptest-poly` 的 `coupled_detached`；
- 初始化：全时刻稀疏点云与第 0 帧稠密点云融合；
- 运动：逐高斯线性项与宽度耦合、梯度 detached 的二三阶多项式残差；
- 存在性：当前最终 transient 时间核配置；
- 生命周期中心：保持已经通过 `coffee_martini` 和 `cook_spinach` 对照实验确认的固定模式；
- static grid 查询：继续使用 detach 后的 Gaussian 规范位置；
- static grid 输出：继续只修正 6 维外观特征，不修改位置、运动、不透明度、尺度、旋转和生命周期；
- 现有初始化、普通增密、多视角结构增密、VAD/TAT、曝光修正、尺度正则和测试流程均由场景最终配置决定，本轮实验不得顺带调整；
- 训练总步数仍为 30,000；
- 紧凑导出继续作为训练完成后的独立步骤，不参与训练优化。

每一个新机制必须由独立配置开关控制，默认值必须保持当前稳定模型行为。旧 checkpoint 和旧配置必须继续可读。首轮实现不修改 CUDA 光栅化扩展。

## 3. 当前实现事实

当前 static appearance 分支可以概括为：

```text
规范位置 x_i^0
    -> 多层 static grid 三线性插值
    -> 逐高斯 static level logits 融合
    -> 视角条件 mapper
    -> static appearance head
    -> 6 维外观残差
    -> 加入逐高斯 features_dc 的前 6 个通道
```

已确认的代码事实：

1. static grid 查询规范位置而不是运动后位置，查询位置已经 detach；
2. static temporal residual 已关闭，static grid 本身不接收时间；
3. static branch 不直接改变运动、不透明度或生命周期；
4. static branch 在前 3,000 步暖启动，此后一直训练到 30,000 步；
5. 当前每次训练迭代在同一时刻选取两个训练视角，跨时间一致性只通过随机迭代和 Adam 隐式处理；
6. view mapper 接收相机方向；
7. `_static_level_logits` 是逐高斯参数，因此当前分支并不是严格的单一空间函数 `F(x)`；
8. 所有能够通过可见 Gaussian 反向传播到 static branch 的像素误差都会更新它，目前不存在显式的共享证据筛选。

## 4. 已有烘焙证据

30,000 步 checkpoint 的只读烘焙诊断得到：

| 场景 | 跨视角标准差 / 平均 static 残差 | 平均视角烘焙相对完整模型 PSNR | 完整模型 PSNR | 平均视角烘焙 PSNR |
|---|---:|---:|---:|---:|
| `cook_spinach` | 0.311% | 82.26 dB | 34.3317 | 34.3356 |
| `Fabien` | 0.410% | 67.44 dB | 35.8184 | 35.8655 |

这些结果支持以下实验结论：训练完成后的真实跨视角变化很小，平均视角烘焙几乎不改变完整渲染，并且没有降低这两个场景的测试 PSNR。

这些结果不能证明“训练时完全不使用相机方向一定更好”。直接绕过已经训练完成的 view mapper 会同时删除它学到的巨大平均变换，因此必须通过从头训练的相机无关版本验证。

## 5. 目标表示

最终希望把训练期 static appearance 分支收敛为：

\[
S(x)=H\left(P\left(\sum_l \operatorname{softmax}(\alpha)_l\,\mathcal I(G_l,x)\right)\right),
\]

其中：

- `x` 仅为 detach 后的规范位置；
- `G_l` 是现有多分辨率 static grids；
- `I` 是三线性插值；
- `P` 是不接收相机方向和时间的共享特征变换；
- `H` 是 6 维 static appearance head；
- `alpha` 的最终目标是全场共享的层级权重，而不是逐高斯身份参数。

训练期允许这个共享场为运动 Gaussian 提供稳定的固有外观。我们只限制它学习观测间相互冲突的补偿，不要求它只服务于物理静止的 Gaussian。

## 6. 总体实验顺序

后续按以下顺序执行：

1. 锁定基线和实验命名；
2. 实验一：相机无关 static 特征变换；
3. 实验二 A：只记录跨观测梯度一致性，不改变优化；
4. 实验二 B：启用一致梯度更新，不冻结 static branch；
5. 实验二 C：在最后一次增密后冻结 static branch；
6. 实验三：把逐高斯层级权重改为全场共享层级权重；
7. 对最终候选重新执行紧凑导出和推理验证。

任一实验失败时停止叠加机制，先分析失败原因。不得把多个尚未验证的变化合并为一次训练。

- 新开关关闭时不改变 checkpoint schema 和前向结果；

## 8. 实验一：相机无关 static 特征变换

### 8.1 唯一允许的行为变化

把当前接收 `static feature + camera direction` 的 view mapper 替换为参数规模相近、但只接收 static feature 的共享变换。保留共享非线性容量，避免把“去掉视角输入”和“减少网络容量”混成同一个变量。

本实验暂时保留：

- 当前多层网格及其分辨率；
- 当前逐高斯 `_static_level_logits`；
- 当前 static app scale；
- 当前 3,000 步暖启动；
- 当前逐步 Adam 更新；
- 当前 30,000 步全程训练，不增加冻结；
- 所有 Gaussian 参数和训练机制。

### 8.2 必须记录

- static residual RMS；
- 共享特征变换和 appearance head 的梯度范数；
- 逐高斯层级权重的均值、方差和熵；
- 训练耗时与峰值显存；
- 标准测试指标与代表性帧；
- 相机无关分支的烘焙一致性。由于前向不再接收视角，理论上最终烘焙应成为代数等价变换；必须用实际渲染验证。

### 8.3 判定

- 若静态区域明显退化，或综合指标超出既有实验波动范围，则不进入一致梯度实验；
- 若整体质量持平或提高，并且动态高频区域没有明显恶化，则将其作为实验二的基础；
- 若指标持平但训练明显更快、显存更低、烘焙变为精确，也保留为有效结果，但是否继续叠加由视觉结果决定。

## 9. 实验二 A：梯度一致性只读诊断

### 9.1 目的

先确认“稳定共享证据产生一致梯度、难以共享的证据产生冲突梯度”是否能在真实训练中被观测到。此阶段只记录，不改变任何参数更新。

### 9.2 统计定义

对 static grid 节点 `v`，在一个证据窗口内记录每个观测产生的梯度：

\[
g_{v,b}=\frac{\partial L_b}{\partial G_v}.
\]

定义一致度：

\[
C_v=\frac{\left\|\sum_b g_{v,b}\right\|}{\sum_b\left\|g_{v,b}\right\|+\epsilon}.
\]

- `C_v` 接近 1：多个观测要求相同更新方向；
- `C_v` 接近 0：更新方向抵消或冲突；
- 梯度为零或支持不足的节点单独统计，不把它们误判为冲突节点。

首轮建议窗口为 8 个训练迭代。当前 batch=2，因此最多包含 16 个逐视角梯度。窗口必须记录实际唯一时间索引数、相机数和有效节点支持数；在获得诊断分布前，不预先固定最终的一致度阈值、支持阈值和指数 `gamma`。

### 9.3 实现约束

- 使用正常训练产生的梯度，不增加额外渲染；
- 在每个视角 backward 后、梯度清零前累计统计；
- 只为 static grids 增加必要的梯度和梯度范数 buffer，不建立逐像素或逐 Gaussian 的长期历史；
- buffer 不写入最终紧凑模型；
- 发生 Gaussian 增密或剪枝不应改变 static grid buffer 形状；
- 诊断不得改变 optimizer step、学习率或随机采样。

### 9.4 日志

每个网格层记录：

- 窗口起止迭代；
- 唯一时间索引数与唯一相机数；
- 有效节点比例；
- 支持不足节点比例；
- `C_v` 的均值、标准差、P10、P25、P50、P75、P90；
- 梯度向量和的范数、梯度范数和以及二者比值；
- 按梯度能量加权的一致度；
- 统计耗时和额外显存。

在少量指定 checkpoint 保存可视化所需的节点统计，但不保存每一步的完整网格张量。

### 9.5 完成条件

- 训练行为和基准指标与实验一相符；
- 一致度不是全 0、全 1 或由数值阈值支配；
- 不同层级、不同训练时期存在可解释的分布变化；
- 统计开销可接受。

只有满足这些条件，才允许把一致度用于优化。

## 10. 实验二 B：一致梯度更新

### 10.1 更新规则

static grid 不再对每个视角的梯度立即执行 optimizer step。一个证据窗口结束后，对节点 `v` 使用：

\[
\widetilde g_v=
S_v\,C_v^{\gamma}\,
\frac{1}{B}\sum_b g_{v,b},
\]

其中 `S_v` 是由有效观测数决定的、detach 的支持系数。`gamma`、最小支持数和一致度下限由实验二 A 的真实分布确定，不在诊断前凭经验写死。

原则：

- 一致度仅作用于 static branch 的反向更新，不进入前向渲染；
- 不让模型学习或反向修改一致度；
- 不改变 RGB 损失；
- 逐高斯外观、运动、生命周期、位置、尺度、旋转和不透明度仍然每一步接收完整正常梯度；
- static branch 在窗口之间继续参与前向，只是延迟更新；
- static grid 的有效学习率必须按更新频率校准，不能因为 8 步更新一次而无意降低 8 倍总更新量，也不能无意放大 8 倍。

### 10.2 共享模块的梯度

- static grid 节点采用节点级一致度；
- 相机无关共享特征变换和 static appearance head 累积窗口平均梯度，并由该窗口按梯度能量加权的全局一致度缩放；
- 本实验暂时保持逐高斯 `_static_level_logits` 的原有更新方式，并在日志中明确把它标为尚未封闭的身份相关通道；
- 如果共享模块的全局缩放导致无法学习，必须单独形成对照，不得静默取消。

### 10.3 对照

- 实验二 A 的相机无关正常优化版本；
- 相机无关 + 只做 8 步平均、不乘一致度；
- 相机无关 + 8 步平均 + 一致度。

“只做平均”对照用于区分收益来自跨时间降低梯度噪声，还是来自一致度筛选本身。

### 10.4 完成条件

- static grid 在高一致度节点上能够继续学习，不发生整体冻结；
- 低一致度梯度被实际抑制；
- 逐高斯分支仍保持有效梯度；
- 静态区域不出现系统性退化；
- 动态高频细节、LPIPS 或视觉残影至少有一项稳定改善，且不是由 Gaussian 数量或其他配置变化造成。

## 11. 实验二 C：增密结束后冻结 static branch

### 11.1 冻结时刻

冻结时刻不是固定写死为 20,000，而是当前配置中所有会改变 Gaussian 拓扑的已启用机制的最晚结束时刻。例如应考虑：

- 普通 densification 结束时刻；
- 多视角结构增密结束时刻；
- VAD/TAT 或其他已启用后期增密结束时刻。

当前常规配置通常对应 20,000 步，但必须由已解析配置计算并在日志中打印。

### 11.2 冻结范围

- 所有 static grids；
- 相机无关共享特征变换；
- static appearance head；
- static level logits；
- 与 static appearance 分支直接对应的 optimizer state 不再更新。

static branch 只冻结参数，仍继续参与前向渲染。20,000 步后的剩余误差由逐高斯参数继续拟合。

### 11.3 对照与判定

只与实验二 B 的“不冻结”版本比较，其他配置完全一致。重点比较冻结前后：

- static residual 是否漂移；
- 静态区域指标；
- 动态高频区域误差；
- 20,000–30,000 步损失与各参数组梯度；
- 30,000 步紧凑导出质量。

若冻结造成静态细节持续欠拟合，则说明最后一次增密结束并不等于 static field 已收敛，应根据日志调整冻结时机，而不能直接否定一致梯度机制。

## 12. 实验三：全场共享层级权重

当前逐高斯 `_static_level_logits` 使两个位于相同规范位置的 Gaussian 可以从相同网格得到不同层级混合结果。这是 static branch 中保留的身份相关自由度。

本实验把它替换为一个全场共享的可学习向量：

```text
static_global_level_logits: [num_levels]
```

所有 Gaussian 使用同一组 softmax 层级权重。此时 static branch 才成为严格的空间函数 `F(x)`。

本实验不得同时改变：

- 网格分辨率；
- 网格层数；
- 一致梯度窗口和阈值；
- 冻结时刻；
- Gaussian 训练配置。

如果全局层级权重导致局部高频静态细节下降，则保留逐高斯层级权重，或者后续另立“仅依赖空间位置的层级路由”研究；不得在本轮直接加入新的路由网络。

## 13. 实验场景与验证顺序

首轮筛选使用两个互补场景：

1. `cook_spinach`：封闭 N3D 场景，静态结构占比较高，已有多次稳定实验和 15k/20k/25k/30k checkpoint；
2. `Fabien`：Technicolor 近景人物，高频动态细节和人物占比高，能够暴露共享场对动态错位的错误吸收。

每个机制先在一个开发场景完成短训练和日志检查，再在两个场景完成 30,000 步对照。只有两个场景都没有明显反例，才进入下一项。

最终候选至少再使用 `coffee_martini` 验证开放场景和远背景行为。是否扩展到全部 N3D 和 Technicolor 场景，在这三个场景得到正结果后决定。

## 15. 评价标准

### 15.1 主要标准

- 标准全图 PSNR、SSIM、MS-SSIM 和 LPIPS；
- 动态高频区域的肉眼质量和误差图；
- 静态区域是否发生可见退化；
- 结果是否超出重复实验的正常波动范围。

### 15.2 机制标准

- static 节点一致度分布是否有效；
- 一致度筛选是否实际抑制冲突梯度；
- static branch 是否仍能学习而不是整体失活；
- 被抑制的误差是否继续向逐高斯外观、运动和生命周期传播；
- 后期冻结是否减少 static residual 漂移；
- 收益是否不是由更多 Gaussian、不同增密窗口或其他场景配置造成。

### 15.3 工程标准

- 不明显增加单步训练时间；
- 不增加额外渲染；
- 额外显存主要来自少量 static grid 统计 buffer，而不是逐像素或逐 Gaussian 历史；
- 旧配置和旧 checkpoint 兼容；
- 紧凑导出仍可用。

## 16. 紧凑导出复核

最终候选训练完成后重新执行正式紧凑导出：

- static grid 特征在最终规范位置查询并烘焙进逐高斯外观特征；
- 相机无关版本不再需要平均多个视角，烘焙目标应是确定的；
- 完整模型与紧凑模型逐帧比较；
- 检查标准指标、最大像素差、运行时间、模型大小和 checkpoint 内容；
- 确认一致性统计 buffer、训练期 static grids、共享 mapper、appearance head 和相关 optimizer state 均未进入最终紧凑模型。

## 17. 明确不在本轮处理的问题

- 可变分辨率或训练中网格细分；
- 新的运动函数；
- 新的生命周期函数；
- static/dynamic 语义分类；
- 外部光流、分割、深度或跟踪教师；
- 根据运动大小对 static grid 做硬掩码；
- static grid 直接生成 Gaussian；
- static grid 修改几何、运动或不透明度；
- 长序列数据加载和训练。

这些问题只有在共享证据训练得到明确结论后，才可以另立实验讨论。

## 18. 已知边界

一致梯度只能识别“多个观测是否要求相近的更新”，不能证明其对应真实物理静态内容：

- 运动物体的稳定固有颜色可能仍被 static grid 学到，这是允许的；
- 在所有观测中方向一致的系统性几何误差也可能被当作共享证据；
- RGB 监督本身无法区分真实稳定外观和跨观测一致的系统性偏差；
- 一致度阈值过强可能让 static grid 失活，过弱则无法限制错误记忆；
- 多层网格不同分辨率可能具有不同梯度尺度，因此阈值必须按层统计，不能直接共用未经归一化的绝对梯度阈值。

因此本轮实验的目标是减少不稳定补偿，而不是宣称得到物理意义上的静态场分解。
